# Level 02 — Close the gap

## Recap (3 lines, top, fades out after 4s)
**Last level:** Local plans left value on the table. The buyer wanted
500, the supplier had 350, they settled at 350 and lost $X.

## Stakes line
What number would have closed the gap?

## Setup
Same two `<AgentFigure>` figures. Between them:
- A wide `<QuantityKnob>` slider running 0 → 600.
- Below the slider: a live `<SurplusBar>` that updates every drag tick.
- A live number below: **"q = 425. joint surplus $Y."**

## Interaction
The user drags the knob. The surplus bar grows and shrinks in real
time. A `<PredictReveal>` wrapper records the user's first guess (the
position they release on for >500ms).

## Reveal
When the user releases at the joint-optimum q (within tolerance ±25
units), both figures swap to `mood="happy"`, the bar locks at its max
green segment, and a Lottie `nod-yes.json` plays on each figure.

One sentence: **"q ≈ 425 is the joint sweet spot. Buyers want more,
suppliers want less; the maximum surplus sits between."**

If the user clicks Continue without finding the optimum within
tolerance, the level shows a "you're close" hint and replays the
reveal at the correct q.

## Continue
Enabled once the user has either found the optimum or has dragged the
knob for 5 seconds total.

## Components used
- `<AgentFigure>` (buyer, supplier; mood switches on optimum)
- `<QuantityKnob min={0} max={600} step={5} />`
- `<SurplusBar value={surplus} lost={gap} />`
- `<PredictReveal>` (tracks user's first release point)
- `<LevelShell>`, `<ProgressDots current={2} />`
