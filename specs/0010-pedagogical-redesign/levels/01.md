# Level 01 — There is a gap

## Stakes line (1 sentence, top of screen)
A factory ships fewer units than a buyer wants. Find out what gets lost
in the gap.

## Setup
Two `<AgentFigure>` figures, side by side, at `size="large"`:
- **Left:** Buyer (neutral). Above the figure: a thought bubble
  showing "wants: 500".
- **Right:** Supplier (neutral). Above: "has: 350".

A wide button below the figures: **"Settle now"**.

## Interaction
The user clicks **Settle now**. No sliders. No knobs.

## Reveal
After a 600ms beat:
1. A horizontal `<SurplusBar>` slides in. The bar shows the joint
   utility under the local plan and a `--surplus-lost` segment showing
   the gap to the joint optimum (computed via `algorithmResults` /
   `labTakeaway` from `@lab/engine`).
2. One sentence under the bar (no antithetical reversals):
   **"Settling at 350 left $X in joint value on the table. Both
   parties acted locally; collectively they lost value."**

## Continue
The Continue button is disabled until the reveal finishes its
animation (~800ms total). After that, "Continue → Level 2" enables.

## Components used
- `<AgentFigure role="buyer" mood="neutral" size="large" motion="wave" />`
- `<AgentFigure role="supplier" mood="neutral" size="large" motion="wave" />`
- `<ThoughtBubble>` (small new helper; renders `wants: X` / `has: Y`)
- `<SurplusBar value={joint} lost={gap} />`
- `<LevelShell />` wrapper

## Engine calls
```ts
import { makeScenario, algorithmResults, labTakeaway } from "@lab/engine";
const scenario = makeScenario({ demand: 500, /* default supplier capacity = 350 */ });
const jit = algorithmResults(scenario).find(r => r.id === "jit-baseline");
const oracle = algorithmResults(scenario).find(r => r.id === "centralized-oracle");
const gap = oracle.globalUtility - jit.globalUtility;
```

The gap value is what `<SurplusBar>` renders as `lost`.

## Completion criteria
- Reveal finished (animation event).
- `learnProgress.markComplete(1)` called on Continue click.

## Voice constraints
- No paragraph longer than 2 sentences.
- No "X isn't Y. It's Z" antithetical reversals.
- No "Cinder" / "Northstar" / "substrate". Use **Buyer** / **Supplier**.
- No "leverage" (the verb sense).
