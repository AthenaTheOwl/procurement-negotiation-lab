# Level 05 — How the rule changes the dance

## Recap
**Last level:** A split is possible when both parties stay above
their walkaway. Who decides the split?

## Stakes line
Different rules of the game produce different deals. Watch three
mechanisms run side by side.

## Setup
Three mini-`<ConvergenceAnimation>` panels in a row:
1. **Centralized oracle** — one planner picks q directly. A single dot
   appears at the optimum after a 200ms beat.
2. **CPP / ADMM** — buyer and supplier alternate. A small grid
   animates: buyer offers price, supplier responds with quantity,
   prices/quantities iterate until they meet.
3. **VCG with transfers** — like ADMM but with a transfer arrow
   appearing from buyer to supplier on convergence.

Below each panel: 3 small stats (final surplus, privacy exposed,
rounds to converge).

A single **Run all** button at the bottom.

## Interaction
The user clicks **Run all**. All three animations play concurrently
(~3 seconds total). The stats fill in as each one finishes.

## Reveal
A side-by-side comparison row highlights the differences:
- Oracle: highest surplus, worst privacy, fastest.
- ADMM: surplus close to oracle, much less privacy exposed, slower.
- VCG: same as ADMM plus a transfer column showing $T to supplier.

One sentence: **"Different rules trade welfare, privacy, and speed.
VCG transfers buy you incentive compatibility — truthful reporting
becomes the dominant strategy."**

## Continue
Enabled after **Run all** completes once.

## Components used
- `<ConvergenceAnimation kind="oracle|admm|vcg" />` (new primitive)
- `<MechanismStats>` (small 3-up summary)
- `<TransferArrow>` (overlay for VCG panel)

## Engine calls
```ts
import { algorithmResults } from "@lab/engine";
const runs = algorithmResults(scenario);
const oracle = runs.find(r => r.id === "centralized-oracle");
const admm   = runs.find(r => r.id === "cpp-admm");
const vcg    = runs.find(r => r.id === "cpp-vcg");
// Each carries iterations, residual, globalUtility, privacyExposure,
// transferMagnitude — feeds the three panels directly.
```
