# Level 07 — Audit the inputs

## Recap
**Last level:** With three parties and a Shapley split, everyone
stayed above their walkaway. The mechanism worked — assuming honest
inputs.

## Stakes line
What if a participant lies about their capacity? The mechanism does
its job; the audit catches the lie.

## Setup
Three-party graph from level 6 stays at the top of the screen.

Below, two stacked sections:
1. **Honesty toggle** — a switch labeled "Participants honest". Off by
   default in this level so the user sees the wrong behavior first.
2. **Decoy outcomes panel** — a list of decoy scenarios (from
   `decoys.ts`) with two columns:
   - **expected pattern** (what the engine predicts under honesty)
   - **actual pattern** (what the dishonest agent produced)
   Mismatched rows get a red bar; matching rows get green.

## Interaction
The user:
1. Looks at the decoys with honesty off — sees mismatches in red.
2. Flips honesty on — sees the rows turn green and the actual pattern
   converge to expected.

## Reveal
One sentence: **"The mechanism settles the deal when inputs are
honest. Audits like the decoy panel catch the gap when they're not.
Both layers matter."**

(Two short sentences. No "X isn't Y" / "the point is".)

## Continue
Enabled after the user has toggled honesty at least once.

## Components used
- `<SourceGraph>` (reused from level 6)
- `<HonestyToggle>` (a labeled switch)
- `<DecoyPanel>` (new — reads from existing `decoys.ts` /
  `runDecoyAudit`)

## Engine calls
```ts
import { makeScenario, runDecoyAudit } from "@lab/engine";
const rows = runDecoyAudit(scenario);
// rows[*] carry decoyId, title, match (bool), expectedPattern,
// actualPattern, catchesMisreportKind, explanation.
```
