# Level 08 — Author your own

## Recap
**Last level:** Honest inputs make the mechanism work; audits catch
dishonest ones. You've seen six concepts: gap, sweet spot, info cost,
walkaway, mechanism choice, multi-party fairness, and audit.

## Stakes line
Now build a participant. Pick a role, edit a utility formula, watch
it negotiate in real time.

## Setup
A simplified `<ParticipantBuilder>`:
- Top: 6 role chips (the same set as the character system). Tap one
  to instantiate.
- Middle: a tiny formula editor (textarea) pre-populated with that
  role's `defaultUtilityFormula` from `data/strategies.ts`. Below:
  parameter sliders for `urgency`, `flexibility`, `truthfulness`,
  `privacyPreference`, `riskAversion`.
- Bottom: a live `<SurplusBar>` showing what surplus the
  custom-participant produces vs the engine's defaults.

## Interaction
The user:
1. Picks a role (e.g., "Logistics").
2. Edits one parameter (e.g., drag `flexibility` to 0.9).
3. Sees the surplus bar change in real time as the engine
   recomputes.

A non-technical user note (small text under the editor): **"You can
edit the formula too. The lab parses what you write; if anything is
wrong it shows you the field and the message."**

## Reveal (graduation)
When the user has clicked at least one role and changed at least one
parameter, a graduation card slides in:

**"You've built a participant. The Sandbox has the full toolkit —
multiple parties, scenario import, run reports, dual review.
Continue when ready."**

A big **"Open Sandbox →"** button below. A small **"Replay levels"**
link in the corner.

## Continue / Graduate
**Open Sandbox** routes to `/sandbox` (today's Lab Arena).

## Components used
- `<ParticipantBuilder>` (subset of the spec 0005 component — role
  chips + parameter sliders + small formula editor)
- `<SurplusBar>`
- `<GraduationCard>` (new — the graduation panel)

## Engine calls
```ts
import {
  buildParticipant,
  multiPartyLedger,
  compileFormula,
  makeScenario,
} from "@lab/engine";

const participant = buildParticipant({ role, parameters });
const scenario = makeScenario({ /* ... */ });
scenario.participants = [...scenario.participants, participant];
const surplus = multiPartyLedger(scenario)
  .reduce((sum, row) => sum + row.utilityAfterTransfer, 0);
```

`compileFormula` (from spec 0003) parses the user-edited formula and
surfaces field-path errors in the textarea.

## Voice constraints for non-technical users
- No undefined jargon. "Utility" is explained on first use.
- The formula editor has placeholder text showing a simple
  example: `service_value * min(q, demand) - unit_cost * q`.
- A `<HelpInline>` button next to the editor opens a small popover
  with the allowed variables, allowed functions, and one worked
  example.
