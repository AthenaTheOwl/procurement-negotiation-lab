# Level 03 — Information moves the sweet spot

## Recap
**Last level:** q ≈ 425 maximized joint surplus. Both parties had to
know each other's costs to find it.

## Stakes line
How much do they actually have to share to get there?

## Setup
Same two figures. Two stacked widgets between them:
- A horizontal `<InfoSlider>` (6 stops): `private` →
  `risk-only` → `capacity-band` → `cost-band` → `forecast-band` →
  `full-oracle`. Each stop has a label.
- A live `<SurplusBar>` (achievable max at this info mode).
- A live `<PrivacyMeter>` (rises with info shared).

## Interaction
The user drags the info slider. The surplus bar grows; the privacy
meter rises. Both `<AgentFigure>` figures cycle moods: at
`full-oracle` they look `worried` (privacy cost is high). At
`private`, the supplier looks `worried` (no signal, hard to plan).

## Reveal
At the `cost-band` or `forecast-band` stop (the "sweet zone" for
recovering most surplus with manageable privacy cost), a green ring
animates around the slider tick. One sentence:

**"Sharing a cost band recovers most of the gap. Going further raises
the privacy cost faster than the surplus rises."**

## Continue
Enabled after the user has visited at least three different info-mode
stops (so they see the curve, not just one point).

## Components used
- `<AgentFigure>` (mood reacts to info mode)
- `<InfoSlider>` (new — 6 discrete stops)
- `<SurplusBar>` (uses engine's `informationSweep` function)
- `<PrivacyMeter>` (new — color `--privacy-cost`)
- `<PredictReveal>` (asks: where's the sweet spot? user clicks a stop)

## Engine calls
```ts
import { makeScenario, informationSweep } from "@lab/engine";
const sweep = informationSweep(scenario);
// sweep is an array of {mode, label, globalUtility, privacy, residual}
// per spec 0001 — already exists in simulation.ts.
```
