# synthetic data

The app uses deterministic synthetic data.

Why:

- public demo should not depend on private procurement records
- tests need stable fixtures
- learning scenarios need controlled failure modes

What is synthetic:

- products
- suppliers
- capacity
- lead time
- risk scores
- evidence cards
- outside options
- penalties

The scenarios are semiconductor-flavored because long-lead planning is legible
there. They are not real supplier records and should not be used for production
decisions.
