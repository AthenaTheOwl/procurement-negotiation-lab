# information value

The app separates perceived context from actual context.

Agents optimize with what they know. The ledger evaluates the final plan against
the actual scenario. That makes information value visible.

Built-in modes:

- private
- risk only
- capacity band
- cost band
- forecast band
- full-information oracle

More information usually improves global utility in the fixed learning scenario.
It also raises information exposure. The app should show both, because information
sharing is not free.
