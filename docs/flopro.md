# FloPro reference

This lab credits the public FloPro repo as the ADMM implementation reference:

https://github.com/amzn/FloPro

The hosted app does not require FloPro or Xpress. It uses a pure-Python
educational ADMM-style implementation so the Streamlit demo stays available.

Future local integration can pin the public FloPro repo as a git dependency and
run the same scenarios through the Vendor Agent Development Kit. That should be
a bridge, not a public-branding change.
